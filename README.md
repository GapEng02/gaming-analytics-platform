# 🎮 Gaming Analytics Platform

A full-stack gaming platform where users can play classic games, track their performance, and compete on leaderboards.

## 🚀 Features

- **Three Games**: Tic-Tac-Toe, Rock Paper Scissors, and Calculator
- **User Authentication**: Register and login with JWT
- **Game Analytics**: Track wins, losses, and performance metrics
- **Leaderboard**: Compete with other players
- **Real-time Updates**: WebSocket integration for live game updates
- **Responsive Design**: Works on desktop and mobile

## 🛠️ Tech Stack

- **Backend**: Node.js, Express, SQLite
- **Frontend**: Vanilla JS, HTML5, CSS3
- **Authentication**: JWT, bcrypt
- **Real-time**: WebSocket
- **Database**: SQLite3
